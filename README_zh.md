# Merge Barrel (合并大木桶)

一个轻量级的 Minecraft Fabric 模组，允许两个相邻的原版木桶合并为一个类似大箱子、拥有 54 格容量的容器，合并放置方法见下文[特性](#特性)。

> **注意：** 本模组需要安装 [Fabric API](https://modrinth.com/mod/fabric-api) 且适用于 Minecraft 26.3+。

## 特性

- **木桶合并**
  - 将两个朝向相同的木桶沿朝向前后放置时，它们会自动合并。
  - 合并后的木桶被视为单一容器。
- **红石兼容**
  - 合并后的木桶可以作为一个整体被红石比较器检测。
- **漏斗自动化**
  - 漏斗可以与合并后的木桶进行整体交互而不是只能对单格容器输入输出。

## 鸣谢
